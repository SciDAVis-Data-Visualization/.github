## What Is SciDAVis

SciDAVis (Scientific Data Analysis and Visualization) is a Windows plotter for people who already keep results in columns. You paste or import, highlight X and Y, and SciDAVis spreadsheet plot appears. SciDAVis curve fitting adds a model. SciDAVis science graph is the window you export. SciDAVis data visualization is the project.

QtiPlot is the scriptable relative. LabPlot is the worksheet-and-live relative. KaleidaGraph and SigmaPlot are paid graphing brands with journal muscle. SciDAVis is the small Origin-like desk: less ceremony, same idea that a spreadsheet is not a figure.

Plot columns you typed, measured, or were given for a course you teach. Keep projects with the assignment or notebook. Do not present another student’s unpublished table as yours.

## Starting with SciDAVis

Prerequisites: A PC you administer and columns from a measurement or assignment you are allowed to plot.

1. **Prepare:** Save the CSV from the bench or the homework table you already have.
2. **Configure:** Import into SciDAVis data visualization and label units on the spreadsheet.
3. **Test:** Create SciDAVis spreadsheet plot of one XY pair and check a point by eye.
4. **Refine:** Run SciDAVis curve fitting, then set fonts for the report you write.
5. **Apply:** Duplicate plots for the remaining columns of that lab.
6. **Maintain:** Store the project with the lab PDF, and start a new file for a new course week.
